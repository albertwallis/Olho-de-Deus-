# Olho de Deus — Android

Projeto Android que empacota o HTML original em um WebView, preservando a interface e permitindo câmera, armazenamento local e internet.

## Compilar
Abra no Android Studio ou execute `gradle assembleDebug` em um ambiente com Android SDK. O APK sai em `app/build/outputs/apk/debug/app-debug.apk`.

Também há um workflow em `.github/workflows/build-apk.yml` para compilar no GitHub Actions.
